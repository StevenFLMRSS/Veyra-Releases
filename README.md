# Veyra

Veyra is a desktop game launcher for Windows and macOS that keeps your games in one library.

This repository only hosts public downloads and update files for Veyra.

## Downloads

Installers will be published under [Releases](https://github.com/StevenFLMRSS/Veyra-Releases/releases). There are no releases yet.

## Installation notes

The current builds are not code-signed with a commercial certificate or notarized by Apple, so your operating system will warn you on first start.

### Windows (SmartScreen)

If Windows shows "Windows protected your PC", click **More info > Run anyway**
(German: **Weitere Informationen > Trotzdem ausführen**).

### macOS 15 and later (Gatekeeper)

If macOS says the app cannot be opened, open **System Settings > Privacy & Security**, scroll to the security section and click **Open Anyway**
(German: **Systemeinstellungen > Datenschutz & Sicherheit > Dennoch öffnen**).
